# Style Of Life — Jewelry Lead Finder (Free MVP)

## Run locally
1. Install Node.js.
2. Open terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## Important
This MVP uses clearly labeled demo lead data. It does NOT pretend demo data is real.
To make it find real USA businesses, connect a lawful business-search/data API to `/api/leads` on the server.
Do not put API keys in `public/index.html`.
WhatsApp button opens a message to the configured number +91 6352925472; it does not auto-send.
