# Style Of Life — AI Shopping MVP

## Run locally
Open `public/index.html` in a browser.

## GitHub Pages
Upload this repository to GitHub and enable Pages from the `main` branch, `/public` folder (or move index.html to root).

## What this MVP includes
- Conversational shopping query
- Budget detection
- Product matching
- Explainable match score
- Responsive U.S.-style shopping UI
- Product/merchant links

## Important
This is a front-end MVP with a demo catalog. It does NOT claim live whole-internet product data.
Next phase can connect legitimate product/affiliate APIs and merchant feeds, then add real-time price, availability, ratings and affiliate tracking.
